# AssetKeeper 1.0.4

- Update popup for Android, Windows and Linux, with release notes and a download
  for the current device. Check manually from Settings, or continue working offline.
- Automated GitHub builds publish a new version only after checks and all three
  platform builds succeed. Ordinary pushes with an already-published version do
  not replace existing downloads or trigger update popups.
- Production Android package and private signing key. This installs separately
  from older test APKs; keep the old app until its inventory has been handled.
- Retains automatic SQLCipher encryption, PC/phone layouts and the clean Android
  splash handoff. Inventory records and encryption keys are never uploaded.

Download opens in your browser. Android asks you to confirm installation. On PC,
close AssetKeeper and replace the extracted application folder. Keep app data,
the original OS account and its saved keys. Windows binaries are not code-signed.
